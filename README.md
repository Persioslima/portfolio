## Projetos em destaque

### Comércio Eletrônico — API REST

API REST desenvolvida com Java, Spring Boot e PostgreSQL para gerenciamento de um catálogo de produtos.

**Funcionalidades implementadas:**
- Cadastro, consulta, atualização e exclusão de produtos, categorias, marcas e etiquetas.
- Relacionamentos entre entidades utilizando JPA.
- Pesquisa de produtos com filtros e paginação.
- Validação de dados e tratamento de exceções.
- Migrações de banco de dados com Flyway.
- Testes automatizados com JUnit 5 e Mockito.
- Documentação técnica com requisitos e diagramas.
